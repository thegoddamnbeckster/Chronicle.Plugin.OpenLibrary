# Chronicle.Plugin.OpenLibrary

Metadata provider plugin for **Open Library**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_OPENLIBRARY.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_OPENLIBRARY.md)

## Supported Media Types

`book`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.OpenLibrary.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> Open Library**
5. Configure required settings (see design doc)
